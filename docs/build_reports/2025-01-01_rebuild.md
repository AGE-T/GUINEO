running.")` on the first call.  The manager reverts the job to
PENDING and would retry (verified by inspecting the retry counter).

SKIPPED.  Verified by direct status inspection.

Result: PASS.

### 6. Feature gate verification

### 7. Integration smoke test

## Known Limitations

1. The built-in YAML emitter in `preset_manager.py` is minimal; it
   covers the preset schema but not arbitrary YAML.  When PyYAML is
   available it is preferred.
2. The BatchManager's retry path uses `QTimer.singleShot` directly,
   which means the BatchManager has a soft dependency on PySide6 for
   the retry timer.  This is acceptable because the BatchManager is
   only ever used in a Qt application; a headless test would need to
   provide its own marshal_to_ui callable.
3. The `SearchReplaceBar`'s "case sensitive" checkbox uses the
   default Qt case-insensitive find; case-sensitive matching is
   applied via `QTextDocument.FindFlag.FindCaseSensitively`.

## Conclusion

All twelve target files compile, all engine modules import cleanly,
and the four smoke tests pass.  The codebase is back to a governed
state with full documentation in `docs/governance/` and verification
tooling in `tools/`.
